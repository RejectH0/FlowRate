# FlowRate Brand Notes

## Primary colors

| Token | Hex | Intended role |
|---|---:|---|
| Aqua | `#00E0D8` | Primary flow / high-energy throughput |
| Sky | `#00B4E8` | Secondary flow / cool transition |
| Indigo | `#6366F1` | Data depth / chart transition |
| Violet | `#A855F7` | Accent / high-end scale |
| Ink | `#0B1017` | Deep background |
| Surface | `#1A1D24` | Main application surface |
| Elevated | `#262A33` | Cards and controls |
| Ice | `#F2F4F8` | Primary text / gauge needle |
| Muted | `#9CA3AF` | Secondary text |

## Semantic-only colors

- Success / average: `#2DDC7E`
- Current marker / warning highlight: `#FFC857`

These two semantic colors should not become dominant brand colors.

## Visual rules

1. Favor deep charcoal/ink backgrounds rather than pure black.
2. Use cyan-to-violet gradients primarily for throughput/data motion, not for every UI element.
3. Keep the needle Ice White so current throughput remains immediately legible.
4. Keep corners moderately rounded to fit the Windows 11 visual language.
5. Use glow sparingly. The production UI should feel precise, not like a gaming dashboard.
6. The layered flow ribbons are a signature motif and can also be reused subtly in website separators, loading states, and empty-state graphics.
7. Use Segoe UI on Windows. For the website, use a modern system sans stack unless the site adopts a licensed web font later.

## Originality

The production mark was created as a new FlowRate-specific composition. It deliberately combines a segmented measurement arc with asymmetric flowing network-data ribbons rather than tracing or recreating a known third-party benchmark or automotive gauge logo.
